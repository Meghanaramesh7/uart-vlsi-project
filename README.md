# UART Transmitter and Receiver using Verilog HDL

## Overview
This project implements a UART (Universal Asynchronous Receiver/Transmitter) using Verilog HDL. It includes both transmitter (TX) and receiver (RX) modules along with a testbench for functional verification.

## Features
- UART Transmitter (TX)
- UART Receiver (RX)
- Verilog HDL implementation
- Functional simulation using EDA Playground and Icarus Verilog
- Testbench verification

## Project Structure

```
rtl/
    uart_tx.v
    uart_rx.v
tb/
    uart_tb.v
```
